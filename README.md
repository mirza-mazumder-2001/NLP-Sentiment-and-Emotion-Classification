# NLP Sentiment and Emotion Classification

A Machine Learning and NLP-based web application developed using Streamlit for:

- Sentiment Analysis
- Emotion Classification

The project uses:
- NLTK
- TF-IDF Vectorization
- Logistic Regression
- Streamlit
- Scikit-learn

---

# Features

## Sentiment Analysis
Classifies airline tweets into:
- Positive
- Negative
- Neutral

Dataset:
- Twitter Airline Sentiment Dataset

---

## Emotion Classification
Classifies text into emotions such as:
- Joy
- Sadness
- Anger
- Fear
- Love
- Surprise

Dataset:
- Emotion Dataset

# Installation

Clone the repository:

```bash
git clone https://github.com/mirza-mazumder-2001/NLP-Sentiment-and-Emotion-Classification.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run Streamlit app:

```bash
streamlit run app.py
```
